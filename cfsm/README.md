# Flat Matrix · CF-Server-Monitor 主题

按用户指定的 https://vps.8899.in 页面和三张参考截图重新实现黑白平面矩阵主题。首页、资源详情和网络延迟页使用 CF 公共接口数据；原仓库根目录 monitor 主题保留，当前 CF 应用在 cfsm/。

## 安装

CF 后台「主题商店 → 自定义主题 URL」填写 `https://github.com/guboysky/CF-Server/tree/cfsm-dist`，预览后应用。固定版本使用构建分支完整提交 SHA。构建根目录只有 index.html 和 assets/。不上传原 theme.tar.gz，不使用源码 cfsm-port 地址安装。

## 页面与交互

- 首页：可折叠的全球平面地图、地区在线列表和筛选；8 项汇总；分币种月/年费用、到期排行；搜索、在线/离线筛选和排序；4 列节点卡片、未接入/离线状态、三网延迟小曲线及平均丢包。手机自动单列。
- 资源详情：节点状态和运行摘要，4 栏系统/内存存储/网络流量/服务周期；历史采样覆盖条；4 项资源汇总，3 个占比圆环，24 个时间分段热力块；CPU、内存、网络对数速率、磁盘长幅曲线。全景/曲线/热力/占比/连接进程切换；扩展 Disk IO 和 GPU 数据有值时展示。
- 延迟详情：线路现值、均值和极值、走势；选中/关闭、单线聚焦；聚合对比、分轨矩阵、延迟排行；智能削峰、时间区间滑块、图例开关、完整日期时间悬浮提示；可切换丢包率。
- 深浅色与地图折叠保存在浏览器。首页标题来自 CF 配置。使用纯色背景以匹配参考图，不叠加旧终端扫描线和图片。

## 数据边界

- config 每站生命周期一次；首页仅一次 servers 快照，后续依赖 WS。独立详情不取列表，只取当前 server、history/all 和当前节点 WS。隐藏恢复只刷新当前快照。
- 全局每秒合并实时数据；无 REST 轮询。布局/筛选/图例/缩放/详情页内切换共用数据，不追加历史查询。仅详情首次进入或用户改时间范围请求 history/all。
- 卡片以列表自带 ping/loss 窗口为起点，追加收到的真实 WS 探测样本，保留最近 1H、最多 600 个点，不为每卡片查询历史。延迟小图根据有效值自动缩放纵轴；常量仍显示直线，不人工生成抖动。窗口按时间排序，延迟为最新有效值，丢包为有效窗口平均值；有符号的 null/false/0 不混淆。详情均值保留有效零值，排除超时、缺失和禁用；不把超时伪造成 100% 丢包。
- CF 内存、磁盘为 MiB，图表转换为字节；traffic_limit 为 GiB，遵守 monthly 和 dl/ul/max/total 口径。计数器差值计算窗口流量，遇重置不计为负值。优先读取后端今日字段；接口没有今日字段时，以本站、节点和本机当天为范围保存计数器差值，明确显示“今日已观测 · 自 HH:mm 起”，不冒充全天。跨天重置，数据每 30 秒保存本机，不额外请求历史。程序端补丁见 docs/backend-daily-traffic.patch，可从当天 D1 记录计算采样流量，仍标明首个有效采样时间。
- 费用按原币种分别折算月费/年费，不编造汇率。虚拟化、备注、位置等缺失字段不补管理接口、不按名字伪造。地图按 CF 提供的国家地区展示代表点，不冒充精确机房位置。
- 覆盖条反映当前范围的真实采样覆盖，不冒充精确 SLA 在线率。没有采样的时间段留空，曲线遇缺失或较长采样空档断开。智能削峰只调整显示范围，不改原始统计。
- CF 参考后端 fa60c60d7a5e872c874fe92822206b32d072c3af 最多支持 168 小时；“30 天”保留禁用入口并说明限制，不发送无效 720 小时请求。仍支持 10/30 分钟、1/6/12/24/48/96/168 小时（时间控件可用标准范围）。
- JWT、Cookie、跨站 WS token、Turnstile 缓存、401/403 和手动继续连接保留。docs/ 中可选后端补丁未部署。原后端公开 note 过滤和 Turnstile 可复用凭证返回缺口仍存在。

## 构建与验证

在 cfsm/ 内执行 `npm ci`、`npm test`、`npm run test:e2e`、`npm run build`，Node.js 22。

28 项单元测试 + 18 项浏览器测试：包含四种公开/Turnstile 模拟组合、401/403、跨站 JWT、连接时限、隐藏恢复、无轮询、零值/缺失/丢包均值、地图筛选、搜索排序、资源视图、热力/占比、延迟矩阵/排行/单线/滑块、未接入状态、桌面和手机无溢出。模拟截图见 artifacts/matrix-*.png。

本地构建连接真实公开站点：12 节点，首页/单机 WS 持续收到 batchUpdate；config、servers、server、history/all 各一次，无页面错误或横向溢出。真实截图只存本机临时目录，未提交真实节点资料。真实私站/Turnstile 开启组合未验收，此记录不表示已替用户应用线上主题。

GitHub Actions 对源码 PR 运行测试与构建；构建分支追加提交、不强推，提交信息与源码一致。旧 Huilang CF 版本可用历史固定提交 fcf201a942ee947435f593e042329304edf5d6e0 安装。

## 紧凑布局调整

全站内容区最大 1380px，桌面四列卡片、较窄屏幕双列、手机单列；地球折叠 SVG 与深浅色按钮并列。卡片不再显示虚拟化/架构文字，系统图标与地区旗帜同排；到期日期使用在线时间后方的独立标签。卡片趋势从 CF 自带的 2 小时窗口按时间戳截取最近 1 小时，显示 1H，不额外请求历史。首次点击详情“网络延迟”时默认加载 24 小时；之后切换延迟子视图、图例、缩放或资源/延迟标签不重复请求，用户改范围才刷新历史。

详情页四个信息面板在桌面端同排，按内容高度压缩；较窄屏幕双列，手机单列。资源详情首次默认 6 小时，网络延迟首次默认 24 小时。

顶部八项汇总与费用/到期区使用紧凑高度；Inter Variable 拉丁字体随主题打包（SIL OFL），中文使用系统苹方/微软雅黑，数字等宽对齐。保持 1380px 居中、桌面四卡片和详情四事实面板。

今日流量程序端改动已准备在 https://github.com/guboysky/CF-Server-Monitor/pull/1 。需更新 CF 程序后才有当天历史采样统计；仅应用主题时显示本机已观测的部分数据。

详情数据审计见 docs/detail-data-audit.md；修复扁平 Disk IO 字段、缺失窗口流量误显示为零、离线覆盖条时间终点、批内实时峰值丢失、长会话截掉旧曲线和 CPU 100% 纵轴翻倍。真实 Windows/Linux 节点悬浮值逐时间戳对照公共接口，真实截图仅保留在本机临时目录。

地球首次使用及本次升级默认收起；顶部图标可展开，之后记住用户选择。流量圆环优先使用整个窗口起点可用的累计计数器；历史缺列时显示“本月流量构成”，再缺失则显示“累计流量构成”，不把打开页面后的少量 WS 样本当作整个窗口。圆环比例和黑色下行图例一致。
