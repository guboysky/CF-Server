# monitor-theme-huilang

为 [monitor](https://github.com/monitor-probe/monitor) 开发的独立静态主题，参考 [CF-Server-Monitor 演示站](https://demo.huilang.me/#/) 的终端文字、透明面板、背景、指标条和多视图布局。接口遵循 [monitor 主题开发文档](https://monitor-document.pages.dev/dev/theme)。

## 安装

在 monitor 管理后台 → 主题，上传 `release/theme.tar.gz`，选择「Huilang 终端主题」。无需修改 hub，无需在服务器安装 Node.js。

上传包的根目录直接包含 `theme.json`、`preview.png` 和 `dist/index.html`，不能再套 `huilang/` 目录；上传安装器会按 short 自动创建目录。手动安装时，先创建 `/opt/monitor/data/themes/huilang/`，再把压缩包解压到这个目录中。

后台的主题设置可调整公告、背景 URL、面板不透明度、默认视图、汇总、卡片价格及延迟记录。站点设置从 hub 读取；每位访客的视图、语言和深浅色偏好保存在自己的浏览器中。背景默认引用演示站同款第三方图片，可清空或改为自己的地址；第三方图片不可访问时仍能使用页面。

## 功能

- 条形图、环形图、列表、离线地图；国家筛选，汇总随筛选更新。
- CPU、内存、磁盘、套餐流量、负载、网速、累计流量、连接数、运行时间、价格、到期天数和公开备注。
- 卡片延迟历史按可见性加载，两个查询并发，每分钟刷新；无监控、请求失败分别显示相应状态。
- 节点详情资源历史、网络延迟、丢包、范围切换、图例开关、缩放及削峰，复用官方主题实现；历史范围来自 hub 保留天数。
- WebSocket gzip / 文本推送、断线重连、5 秒轮询兜底、10 秒断流检查、前后台恢复。
- 移动布局、深浅色与跟随系统；概览提供中英文，历史详情沿用官方中文界面。

## 与参考站的适配差异

公开接口没有 IP 地址和精确坐标，因此卡片不展示 IP 类型，地图按国家着色；缩放后可滚动，国家按钮用于筛选。汇总第四项显示本月流量，不估算跨币种「剩余价值」。不实现 CF 的后台、第三方汇率或 agent 控制功能。管理后台可直接访问 monitor 自带的 `/admin`。环形图展示 CPU / RAM / DISK，条形图额外展示套餐用量。价格开关仅控制概览卡片，详情显示接口提供的续费资料。

## 本地开发

要求 Node.js 24+，使用 pnpm（或 npm）。

```powershell
pnpm.cmd install --frozen-lockfile
$env:MONITOR_HUB = 'https://你的探针域名'
pnpm.cmd run dev --host 127.0.0.1
```

不设 `MONITOR_HUB` 时代理到 `http://127.0.0.1:9911`。无需填写 token，目标 hub 必须开放公开状态页。

无 hub 时可访问 `http://127.0.0.1:5173/?demo` 查看明确标注的静态演示。需要测试真实 API 格式、gzip 推送及历史图表时，另开终端运行 `pnpm.cmd run mock:hub`，再访问 `/`。这是本地测试服务，数据全为模拟。生产构建禁用 `?demo`，测试服务不进入安装包。

```powershell
pnpm.cmd run test
pnpm.cmd run build
pnpm.cmd run pack
```

打包脚本使用系统 `tar`，输出 `release/theme.tar.gz`，检查 gzip 尾部、根目录 theme.json 与 dist/index.html、包内清单、文件数量及安装大小上限。`release/stage-*` 是打包时保存的目录副本。要发布到 GitHub，应填写 `theme.json` 的 author 和源码 url，release tag 与 version 对齐，把资产命名为 `theme.tar.gz`。当前未配置发布仓库，不能从 GitHub 一键更新。

## 路由与资源

概览 `/#/`，详情 `/#/node/{id}`，使用 hash 路由，刷新详情无需额外反代规则。hub 保留 `/admin` 与 `/api`。站点图标引用 `/favicon.svg` 与 `/apple-touch-icon.png`，支持 hub 覆盖。地图文件 `/world.json` 随包附带，不依赖在线瓦片。

## 1.0.1 界面调整

列表使用统一表格，每行一个节点：主机名、地区代码、系统/架构、CPU、内存、磁盘、套餐用量、TCP/UDP、下载、上传、更新。显示状态圆点和系统图标，点击行或节点名进入详情；手机保持表格并可横向滚动。更新时间采用 hub 的 last_seen_ago，离线或尚未上报的实时指标显示「—」。视图切换合并为下拉框；移除跟随系统、浅色及后台的三个独立图标，保留一个深浅色切换按钮。详情去掉顶部重复卡片，仅展示节点资料和历史图表。

## 1.0.2 界面调整

四种视图分开为按钮，放在页头工具栏的语言按钮之前，不再使用下拉框。删除名称搜索、分组筛选、分组标题和节点数量标题，卡片按照接口原有节点顺序连续排列。列表仍保持一行一个节点。页头探针名称直接读取 `/api/me` 的 `site_name`，在 monitor 后台修改站点名称即可；演示预览使用「探针名称」作为占位文字。

## 1.0.3 界面调整

概览四种视图和详情统一使用 1480px 最大内容宽度；宽表格在容器内部滚动，不再放大整个页面。探针名称移至顶部圆点右侧。视图按钮在详情也显示，点击后返回对应概览；删除三点提示入口。详情资料按参考效果整理为七列、两行的表格，包含运行时间、到期、系统/架构、内核、CPU、磁盘/内存、负载、流量、网速、配额、启动时间、更新时间及 agent 版本；手机显示两列。无上报或无数据时显示「—」，不推算不存在的数据。

## 1.0.4 界面调整

卡片延迟记录与丢包记录拆为左右两段，中间留 18px 空隙。左侧按延迟着色，右侧按各历史时间点的丢包比例着色，两侧均展示最近 15 个采样。详情返回按钮移到节点名称前，删除名称后的 `:~#` 和原先独立的返回栏。

## 1.0.5 显示优化

删除站点名称前的 `$`。所有概览视图先显示在线节点、再显示离线节点，同类节点保留 hub 原顺序。延迟曲线改用彩色实线，默认按屏幕宽度和时间范围请求趋势采样：一周及更长最多 200 点，手机最少 90 点；采用 hub 返回的时间段延迟中位数和丢包信息。「详细采样」恢复 1440 点上限，保留削峰、图例及缩放操作。图表高度限制在 320–480px。

## 1.0.6 手机与图标修正

Windows 系统在卡片、列表及详情统一使用 Windows 图标，不再回落为 Linux。隐藏空白、unknown、none、n/a 的虚拟化标签，保留有效的国家和架构标签。手机顶部固定为两行：第一行四种视图，第二行语言和深浅色，避免单个按钮掉行。概览汇总仅显示实时速度，删除服务器数量、总流量及本月流量；节点详情和卡片自身的流量资料继续保留。

## 1.0.7 汇总显示修正

PC 端恢复服务器数量、总流量、实时速度、本月流量四项汇总。只有 700px 及以下的移动布局隐藏服务器数量、总流量、本月流量，保留实时速度。Windows 图标、unknown 标签隐藏及手机按钮对齐的修正继续保留。

## 1.0.8 手机精简

手机隐藏地图及 EN/中语言按钮，三个视图和深浅色按钮放在同一行；PC 全部保留。国家筛选改为等宽网格，360px 及以上每行五项，更窄手机每行四项，减少行尾空白。延迟图去除 SVG/图表容器聚焦时的外框，保留曲线、网格、提示和缩放。

## 1.0.9 手机顶部与图表聚焦修正

仅手机把三个视图和深浅色缩小至 26px 高，放到名称右侧同一行；长名称省略显示，PC 布局不变。手机延迟图关闭 Recharts 键盘可访问聚焦层，并清理图表内部 SVG/缩放控件的聚焦轮廓及触摸高亮；PC 可访问层和样式不变，手机仍支持点击提示和缩放。

## 1.0.10 动态环形指标

CPU、RAM、DISK 使用 SVG 进度环，首次显示从零展开，实时快照变化时以 650ms 过渡到新值。RAM 有 Swap 配置时显示第二层内环及百分比。指标保持真实数据，不使用随机数或持续旋转模拟活跃；离线/未上报显示「—」。尊重浏览器减少动画偏好。

## 1.0.11 中文标注与地图匹配

中文界面卡片 LOAD/NET/TRF 改为「负载/网速/流量」。底部主题文字链接到 https://github.com/guboysky/CF-Server。地图增加按地区独立计数的位置标记，香港、澳门、台湾、新加坡不再因地图轮廓缺失或面积太小而漏显示；其他国家从最大主体区域计算代表位置。标记点击可筛选对应国家代码，无法匹配的代码注明未能定位，空/无效代码归入未知国家。位置表示国家/地区，不是服务器精确坐标。增加真实地图文件上的 CH/FR/HK/MO/TW 等代码匹配测试。

## 1.0.12 地区显示与中文指标

统一地区码去除空白、转换大写，地图、筛选、列表和国旗使用同一格式。实时推送省略 country 字段时，保留当前会话中同 ID、同名称节点的已有地区；接口明确返回空地区时显示「未知地区」，不猜测位置。国旗加载失败显示地区码，避免空图。新地区码覆盖旧值，同 ID 更换节点名称不继承地区。列表、卡片和环形图的 CPU/RAM/DISK/USE 改为「处理器/内存/磁盘/用量」。

如果节点始终没有地区，原因可能是 hub 自动 IP 地区查询失败、限流或没有可定位的公网地址；在 monitor 后台编辑节点并设置国家/地区，可稳定显示。主题公开接口不含 IP，因此不会自行查询公网 IP 或根据主机名称推断位置。

撤回 1.0.12 的指标中文化：卡片与环形图恢复 CPU、RAM、DISK、USE，列表及详情的 CPU 名称恢复。负载、网速、流量仍使用中文。地区码标准化、推送缺字段保护、国旗加载回退等修正保持。
